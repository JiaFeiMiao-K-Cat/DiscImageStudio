# Política de seguridad

> Traducción al español · [Original](SECURITY.md)

No reveles vulnerabilidades explotables en incidencias públicas. Usa **Security → Report a vulnerability** del repositorio de GitHub para informar de forma privada e indica la versión afectada, los pasos de reproducción y el alcance del impacto.

El proyecto no se conecta activamente a la red, pero analiza imágenes, directorios e imágenes de disco que se seleccionan. Los problemas de análisis de archivos, gestión de rutas, manifiestos de paquetes o entradas no confiables deben tratarse como cuestiones de seguridad.

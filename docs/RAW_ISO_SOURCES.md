# 原始 ISO 与 CUE/BIN 源（实验性）

本文说明设计页「随盘文件」中的 ISO 镜像源和 CD CUE/BIN 源。原始 ISO 导入当前属于实验性功能；请先导出到文件并检查结果，再使用可报废的测试盘验证刻录。

## 在哪里使用

在设计页打开「随盘文件」，为当前盘型选择 ISO 镜像。CD 还接受 CUE 文件；DVD 和蓝光只接受 ISO。ISO 源与文件夹源是互斥的，不能同时配置。选定源后，设计预览和成品读回会以蓝色标出 ISO 数据区域。

## 原始 ISO 的行为

- 输入必须是非空的 `.iso` 文件，长度是 2048 字节逻辑扇区的整数倍，并且不超过本次输出容量。
- 当前识别 ISO9660 主卷描述符，或 UDF 的识别序列；识别只检查卷描述符和基础容量字段，不会遍历文件系统、修复镜像或验证其中每个文件。
- 输入镜像的逻辑扇区从输出 LBA 0 开始逐字节保留。图案只生成在其后的可用区域，不会覆盖源前缀。
- DVD 的图案起点需落在完整 ECC 块边界，源 ISO 后可能留出未用于图案的对齐间隔。若剩余空间不足一个完整图案块，生成会失败，而不是输出部分块。
- ISO 占满可用空间时，不会有图案区域；不同介质仍会执行各自的容量与扇区布局校验。
- 导出到文件时，输出路径不能覆盖源 ISO。即时刻录使用同一扇区生成路径；CD CUE/BIN 则不支持在应用中即时刻录。

## 支持范围与注意事项

「原样保留」指 ISO 中已有的逻辑扇区，不代表实体光盘的物理克隆。普通 ISO 不包含隐藏轨道、子通道、盘片前导/导出区、物理介质特性或其他未被镜像捕获的信息。将 CD ISO 放入 DVD+R 或 BD-R 时，保留的是原始逻辑扇区数据；这不会把 CD 转换成目标介质的原生文件系统，也不保证所有依赖特定 CD 物理结构的程序都能正常工作。

源镜像应来自可信来源并由用户自行确认其合法性。请妥善保留原始文件；应用不会修改它，但输出可能因介质容量或选择的盘型而包含额外图案扇区。

## CD CUE/BIN 独立导出

CUE/BIN 与原始 ISO 混合生成是两条不同路径：受支持的 CUE 会将引用的 `BINARY` 轨道文件按原字节复制到导出目录，并重写 CUE 引用。该功能不把轨道与图案合并，也不支持应用内即时刻录，需使用支持多轨道的刻录软件。

目前仅支持相对路径且位于 CUE 所在目录下的 BINARY 文件，以及程序识别的常见轨道模式和每轨 `INDEX 01`。不支持的文件类型、轨道模式、绝对路径、越出 CUE 目录的引用或缺失轨道会明确报错。复杂的 CUE 特性及其他光盘映像格式不在当前支持范围内。

## 实测记录

已使用人民教育电子音像出版社的《物理必修一》CD-ROM 进行一次实体盘验证：先将原 CD-ROM 读取为 ISO，再通过原始 ISO 源功能导出并写入 DVD+R。用户报告程序流程正常，光盘内容可读取，盘面图案纹理清晰。读取 ISO 时的预读取速度略慢；考虑到生成过程还需采样与计算盘面图案，该速度表现可以理解。此记录是一次具体介质与设备上的结果，不构成对所有光驱、镜像和空白盘兼容性的保证。

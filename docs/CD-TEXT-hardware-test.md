# CD-TEXT 与 CD Extra 实机测试清单

开发环境没有 Windows 和光驱。下表区分了已经模拟验证的部分和必须在实机上确认的部分。

## 已模拟验证（无需光驱）

| 项目 | 方式 |
|---|---|
| CD-TEXT 数据包编码 | 与 libburn 文档中 cdrecord 生成的 22 个数据包逐字节一致；CRC 与 6 位 R-W 拆分与 libburn cookbook 示例一致 |
| 日文曲名 | MS-JIS（语言码 0x69）编码后解码不变；简体中文中 JIS 没有的字会列出并写成“？” |
| 超长文字 | 超过一个块（253 个文本包）时在写入前拒绝 |
| SAO cue sheet | 导入区带 CD-TEXT 标志，各音轨 INDEX 00/01，导出区；音轨起点与导出区地址与原 TAO 计划完全相同 |
| CD Extra 刻录流程 | 脚本化 SAO 光驱：导入区、150/152 块静音预间隙、音轨、末尾 2 块静音、完成会话，然后按原 TAO 代码写第 2 区段并封盘，再读回 CD-TEXT |
| 读回与曲序 | 读回的数据包解码后与设置比较；调换曲序、数据包损坏都会报告 |
| 不支持时的回退 | 光驱不报告 SAO 或拒绝 cue sheet：弹窗确认，盘片尚未写入；确认后走原 TAO / IMAPI 路径，拒绝则取消 |
| 纯图片音频 CD | 单轨 SAO 并封盘；不支持时回到原 IMAPI DAO 路径 |
| 保存 | .discproj（schema 4）、package.cdextra.json、CUE 的 TITLE/PERFORMER 与 .cdt 往返 |
| CD Extra 窗口的 CD-TEXT | 窗口自带逐曲表：默认取本窗口音乐的标签，可改用设计页信息（按文件路径对应），改动后切换会先询问；查找只改本窗口；非拉丁字母字段标出（整盘改用 MS-JIS）、MS-JIS 无法表示的字符点名，准备刻录包前用应用内确认卡片列出；MusicBrainz 拉丁字母版曲目表与艺术家英文名、503 重试，Apple 区域；所有网络请求用替身（`--test-album-info`） |
| 设计页非 WAV 音乐 | CD 格式 WAV 原样使用、不进缓存；其他文件后台转换到缓存，列表与工程保留原路径；源文件改动后重新转换；解码失败标红；转换期间布局等待；缓存按 30 天未用和 2 GB 上限清理（`--test-music-sources`，解码器用替身） |

## 需要在实机上测试

准备：Windows 10/11 x64，支持 SAO 的刻录机（如 ASUS DRW-24D5MT），空白 CD-R 若干，一台能显示 CD-TEXT 的 CD 播放机或电脑软件（foobar2000、EAC、ImgBurn 的“读取 CD-TEXT”）。

1. **能力检测**：在设计页打开 CD-TEXT 并填写文字，开始刻录。日志应出现“CD-TEXT 写入能力：SAO=True…”。记下 MaxCue 等数值。
2. **CD Extra + CD-TEXT（含日文）**：2–4 首音乐，曲名中至少一首日文，专辑名、艺术家各一。刻录完成后检查：
   - 四个里程碑：写入完成、已封盘、读回校验通过、**CD-TEXT 读回一致**；
   - 日志中“第 2 区段起点 LBA”与设计页预测值一致（SAO 第 1 区段后应与 TAO 相同）；
   - 在 CD 机上播放：曲目数、曲序、专辑/曲名/艺术家显示正确，第 2 区段图案不会被当成音轨播放；
   - 电脑上读取 CD-TEXT（如 EAC），文字与曲序一致。
3. **纯图片音频 CD + CD-TEXT**：不加音乐，只填图片音轨的曲名/艺术家。刻录后应封盘，CD 机显示文字。
4. **不支持 SAO 的光驱（如有）**：应弹出“光驱无法写入 CD-TEXT”。选“不带 CD-TEXT 继续”，结果应与不使用 CD-TEXT 时完全相同；选取消，盘片应仍为空白。
5. **CD-TEXT 关闭**：同一工程关闭 CD-TEXT 刻录一张，确认行为、日志与加入 CD-TEXT 之前相同。
6. **刻录包**：在 CD Extra 窗口勾选“写入 CD-TEXT”（默认不勾选）准备刻录包，重新打开刻录包后刻录，结果同第 2 项；重新打开后逐曲表应显示刻录包里的文字，来源列为“刻录包”。
7. **导出**：导出 WAV+CUE，确认 CUE 中有 TITLE/PERFORMER 与 CDTEXTFILE，用 ImgBurn 等软件按 CUE 刻录时能读到文字。

8. **设计页导入非 WAV 音乐**：在设计页分别添加 MP3、FLAC、M4A（AAC）、WMA 和一个 48 kHz 的 WAV。每行先显示“正在转换为 CD 音频…”，随后显示时长，时长应与播放器一致；音轨范围盘与区段占比随之更新。CD-TEXT 应从这些文件的标签自动填入曲名。保存工程、关闭再打开，列表仍是原文件；`%LOCALAPPDATA%\DiscImageStudio\MusicCache` 中有转换后的 WAV。导出 ISO 与刻录各一次，CD 机播放应与原曲一致（MP3/AAC 曲首曲尾可能有极短静音）。改一个源文件（例如重新导出）后，应重新转换。
9. **CD Extra 窗口的 CD-TEXT 来源（需联网，不需光驱）**：
    - 设计页填好 CD-TEXT 后打开“导出 → CD Extra”：“写入 CD-TEXT”默认不勾选；勾选后来源默认为“本窗口导入的音源”，逐曲表的曲名来自本窗口所加文件的标签（无标签时为文件名），来源列显示“标签”/“文件名”。
    - 改选““设计”页的信息”：设计页里同一文件的曲名填入，来源列为“设计页”。手动改一格后再切回，应先弹出软件自己的确认卡片。准备刻录包后，回到设计页确认其文字没有变化。
    - 字段检查：含中文或日文的字段边框变为警示色，悬停说明原因（整盘改用日文 MS-JIS；简体字等无法写入的字会点名）。点“准备刻录包…”时应先弹出“检查 CD-TEXT”卡片逐项列出；全部改成英文或罗马字后不再提示，状态行显示 ISO-8859-1。用这样的全拉丁字母盘在 Windows 媒体播放器和 VLC（断网）上检查显示是否正确。
10. **在线查找**：点“在线查找专辑信息…”，用 MusicBrainz 搜一张日文专辑（如 椎名林檎《無罪モラトリアム》）和一张华语专辑（如 周杰伦《叶惠美》）。每次搜索前应弹出软件自己的确认卡片，列出要发送的文字；点“取消”或按 Esc 时不应联网。点选结果后右侧逐项对照；日文专辑应显示罗马字或英文曲目表，艺术家为英文名；只勾选部分行，确认只有这些行变了，来源列为“MusicBrainz”。再改选 Apple Music，香港区为默认，分别试日本区、美国区。
11. **CD Extra 刻录确认**：在 CD Extra 窗口点“刻录此包…”，应弹出软件自己的“确认 CD Extra 刻录”卡片（不是 Windows 系统弹窗），默认焦点在“取消”，按 Esc 取消。“图案断点续写与校验”和“光驱无法写入 CD-TEXT”也是同样的卡片。
